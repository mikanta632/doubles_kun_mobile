# ダブルスくんモバイル

ダブルスの組み合わせをその場で作るアプリのブラウザ版。スマホのホーム画面に追加して使う。

**公開先**: https://mikanta632.github.io/doubles_kun_mobile/

デスクトップ版（PySide6）の中核ロジックを TypeScript に移植したもの。組み合わせエンジン、
一括計画（焼きなまし）、Elo、一日の指標、ペア強度モデルの推定はデスクトップ版と同じ結果を出す。
`tests/golden/` にデスクトップ版が書き出した正解データがあり、乱数の消費順まで揃えて
一致を確認している（`tools/make_golden.py`）。

## 使い方

1. 試合タブの見出し（プロジェクト名）をタップして、名前・日付・場所を入れる。新しいプロジェクトもここで作る
2. メンバータブの「追加」で名簿を作る（データベースから選ぶか、名前を登録する）
3. メンバータブで、今日試合に入れる人にチェック
4. 試合タブで、空いたコートの「次の試合を組む」。案を見て採用する（右上のボタンで何試合ぶんかをまとめて組むこともできる）
5. 「結果を入力」か記録の行をタップして結果を入れる。記録は長押しして動かすと順番を入れ替えられる
6. 集計タブで、成績や出場回数・待ちの偏りを確認する（名簿の人だけが対象）

メンバーは 3 層になっている。データベース（端末に登録した全員）→ プロジェクトの名簿 → 試合に入れる人。
プロジェクトは複数作れて、試合タブの見出しから切り替える。名簿・試合・設定はプロジェクトごと、データベースは共通（設定タブの「メンバーのデータベース」で編集する）。

データはブラウザの中にだけ保存される。設定タブから JSON で書き出せる。
`players.json`（名簿）と `matches.json` はデスクトップ版のプロジェクトフォルダにそのまま置ける。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 正解データとの突き合わせ
npm run build    # dist/ に出力
```

正解データを作り直すときは、デスクトップ版のリポジトリを隣に置いて

```bash
npm run golden
```

`main` に push すると GitHub Actions が GitHub Pages に配信する。
